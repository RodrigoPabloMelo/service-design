# Glossário

> **Atualizado:** 2026-10-16

| Termo | Significado no projeto |
| --- | --- |
| **Rolê** | Qualquer passeio, lugar ou experiência recomendada (café, bar, evento, restaurante, passeio). Unidade básica do app |
| **Não-turístico / local** | Lugar ou experiência frequentada por moradores, fora do circuito turístico tradicional. Não exclui pontos famosos — elas querem os dois |
| **Local** (`A-1`) | Pessoa que recomenda rolês: moradora/or comum ou criadora de conteúdo de Recife/Olinda |
| **Prestador(a) de serviço** (`A-6`) | Negócio ou pessoa que oferece o rolê (restaurante, guia, transporte) e paga comissão |
| **Grupo** (`A-2`) | A equipe do projeto (Rodrigo, Eulália, Maria Clara), responsável pela curadoria e pela sustentação do app |
| **Curadoria** | Filtragem das recomendações por critérios do grupo + avaliações da comunidade |
| **Viajante** | Usuária final: mulher viajando sozinha ou com mais 1 pessoa. Aparece no ecossistema em três momentos: antes (`A-4`), durante (`A-5`), depois (`A-7`) |
| **Companhia** | A amiga ou parceiro(a) que viaja com a viajante |
| **Contexto do entorno** | Informação sobre região, horário, acesso, ida/volta e movimento ao redor de um rolê |
| **Selo de segurança** | Avaliação feita por usuárias sobre quão tranquilo/adequado o lugar é (ex.: para ir sozinha) |
| **Planos/pacotes** | Ofertas pagas com benefícios extras (motoristas mulheres, reservas, pratos sugeridos) |
| **Crédito/desconto** | Recompensa dada a locais pelas recomendações, usável em rolês do app |
| **Publi** | Conteúdo patrocinado que parece recomendação espontânea — principal fonte de desconfiança |
| **Piloto** | Recife/Olinda, primeira praça do serviço |
